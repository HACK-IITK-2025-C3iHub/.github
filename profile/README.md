# HACK-IITK-2026-C3iHub

This organization hosts the development of a **Local LLM system** designed specifically for **Policy Gap Analysis**. Developed for the **HACK-IITK-2026** hackathon at **IIT Kanpur**, the project focuses on identifying inconsistencies and security vulnerabilities within organizational policy documents using locally hosted AI.

---

### 🛠️ Core Project

The primary repository contains the interface and integration logic for the local model.

* **[Local-LLM-UI](https://github.com/HACK-IITK-2025-C3iHub/Local-LLM-UI)**: Python-based user interface for managing local LLM inference and policy document processing.

---

### ⚙️ Technical Stack

* **Language:** Python 3.x
* **AI Infrastructure:** Local LLM hosting (Ollama / Transformers)
* **Focus:** Private, offline policy analysis and gap detection.
